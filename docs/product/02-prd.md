# 02 骨架定位

## 1. 定位

本项目是本地桌面工具骨架，不是面向最终用户的业务产品。

它帮助新项目快速获得：

- Tauri 2 桌面壳
- React + TypeScript 前端基线
- Apple/macOS-inspired 桌面工具界面
- SQLite migration 与 repository 模式
- 设置弹窗、主题偏好和通用 UI primitives
- Vitest、Testing Library、Playwright 验证基线

## 2. 目标用户

目标用户是需要快速启动本地桌面工具的开发者。

## 3. 当前承诺

- 骨架能启动、构建和测试
- 示例记录链路能演示数据层读写
- UI 组件和布局可被后续业务复用
- 不携带特定业务域或敏感数据语义

## 4. 不承诺

- 多用户协作
- 权限管理
- 云同步
- 远程 API 集成
- 插件系统
- 真实业务闭环

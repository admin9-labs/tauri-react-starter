# 03 示例流程

## 1. 打开应用

1. 应用进入 `#/dashboard`
2. 用户看到骨架能力概览
3. 用户可从侧边栏进入记录页

## 2. 示例记录

1. 用户进入 `#/records`
2. 空数据时展示 `EmptyState`
3. 点击 `生成示例`
4. repository 写入 `example_records`
5. 列表展示示例记录
6. 点击标题进入详情页

## 3. 详情编辑

1. 用户进入记录详情
2. 点击编辑
3. 修改标题、摘要或状态
4. 保存后 repository 更新记录
5. 删除时必须经过 `ConfirmDialog`

## 4. 设置

1. 用户点击侧边栏底部设置按钮
2. 设置以弹窗展示
3. 用户切换主题偏好
4. 偏好写入 `localStorage`

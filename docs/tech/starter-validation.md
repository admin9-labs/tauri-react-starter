## 浏览器与原生运行

- 浏览器验证概览、25 条记录及筛选、连续保存、删除、读取/刷新/保存失败及重试、组件通知、三种主题和命令导航。
- 原生使用独立临时数据目录，从空库生成 3 条记录；连续编辑其中一条并删除另一条，退出重启后准确保留 2 条。页面值与只读 SQLite 检查一致。
- 默认 1180×760 与最小 1100×680 逻辑尺寸下检查变更相关的明暗详情、编辑、列表和命令面板；结合未变化布局的完整视觉矩阵，主要控件可达。
- 原生实测 Tab/Enter 保存、Esc 关闭设置及取消删除、命令搜索执行，以及浅色、深色和跟随系统主题。

原生使用可丢弃验收数据，没有操作真实用户数据库。README 中的 [浅色概览](../images/dashboard-light.png) 为公开源码准备时采集的浏览器示例画面，不作为原生运行证据。

## 开源准备与证据复用

公开前核对 135 个原有跟踪文件的指纹及工具版本，均与已审阅的本地基线一致。运行时与数据层没有新增能力或 schema 变化；相关单测、E2E、浏览器和原生证据可复用。

本次另补项目元数据、MIT 许可证、素材声明、贡献与安全报告入口、公开 README 和预览图，整理验收说明，并移除无对应文件的 Vite favicon 引用。字体内嵌元数据确认版权与 OFL 1.1，原生图标与官方模板逐个核对一致。

原始本地日志、源码指纹及 SQLite 核对结果保留在仓库外，不向源码仓库加入生成的用户数据、调试包或完整测试附件。公开自动检查日志由 GitHub Actions 提供。

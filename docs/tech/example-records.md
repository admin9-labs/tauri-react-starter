# 示例记录模块

`example_records` 是骨架内置的最小示例模块。

## 目的

- 展示 migration 怎么注册
- 展示 repository 怎么封装 SQL
- 展示列表页、详情页、编辑和删除交互
- 给测试提供稳定的业务替身

## 替换规则

新项目落地真实业务时，应沿用模块结构并同步替换：

- 表名
- 实体类型、mapper、repository 输入输出及 barrel 导出
- Rust migration SQL 与 TypeScript migration 描述
- 浏览器 mock 的行、存储、查询和更新分支
- 页面、路由解析、应用分发、导航及相关命令入口
- 测试数据、字段断言和页面文案

完整改名与验证顺序见 [开发者入口](../tech/developer-start.md)。不要把真实业务长期挂在 `example_records` 上。

## 返回值与失败

- `findById()` 返回 `null` 表示查询成功但记录不存在；读取抛错是另一种状态，应显示可重试的错误说明。
- `update()` 返回记录才算保存成功；返回 `null` 或抛错都保留编辑内容，避免误报成功。
- 列表刷新失败保留已有结果并提示尚未刷新；成功重试后清除提示。
- 浏览器 mock 只覆盖本示例查询，不证明真实 SQLite 事务或迁移行为。原生连接失败不会回退到 mock。

列表使用 `findAll()` 加载完整示例集合，计数和筛选覆盖全部记录。`findPage()` 保留给需要分页的调用方，页面没有隐含的 20 条显示上限。
